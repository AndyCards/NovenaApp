# pocketNovena
A free, private, offline-first novena prayer app for iPhone and Android (Expo + React Native).
## Run it
1. Install Node LTS, then run `npm install` in this folder.
2. `npx expo install --fix` (lines up library versions with Expo).
3. `npm run ios` or `npm run android`.
