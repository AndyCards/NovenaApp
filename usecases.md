# pocketNovena use cases

The app is built to look exactly like Figma Page 34. These use cases shape how it works underneath.

## Discover (Home)
1. Browse 50 to 70 novenas. Content updates from the server without an app update.
2. Themed sections set in the Excel "Collections" tab (for example Mental health, Popular, Marian), so Home changes when the sheet changes.
3. First-time users see "How a novena works"; returning users see a "Continue praying" carousel.
4. "What are you praying for?" intention tiles lead to matching novenas.
5. Featured carousel with a Start Novena button.
6. Search: suggestions while typing, recent searches, filters (All, By intention, By saint, With audio), no-results and offline messages.

## Novena page
7. Saint image, about text, minutes per day, tags, and all 9 days shown as prayed, today, missed or coming up.
8. Start novena, Continue with Day N, Save for later.
9. Missed-days warning: pray the missed day or continue with today's day.
10. "Novena complete" with Pray it again and Share.

## Reader
11. Any day can be opened; Start/Continue always goes in order from the last day prayed.
12. Listen or Read only. Audio never starts by itself.
13. Player bar: play, pause, seek, loading, offline, error.
14. Private intention: write and view it. It stays on the phone.
15. Mark Day N as prayed, then a "Day prayed" confirmation with a week strip and Share.
16. Options menu: save the novena, download audio for offline.
17. "Continue another time?" when leaving without praying.

## Library
18. Active, Completed and Saved tabs, each with its own empty state.
19. Pause, resume, start again from Day 1, remove with Undo.

## Reminders
20. Daily reminder on/off, time and weekdays.
21. Missed-day note, feast-day suggestions, quiet hours.
22. Turn reminders off for one novena.
23. A banner when phone notifications are off.

## Calendar and sharing
24. Month and year views with prayed days, feast days, and when each feast novena should start.
25. Share a saint card or prayer as an image. Intentions are never included.

## Under the hood
26. Works offline, needs no account, and is backed up by the phone's own backup.
